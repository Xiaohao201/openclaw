# 侵权研判与投诉通知

对用户提供的涉企负面舆情进行法律定性研判，并生成标准化的平台投诉通知。

当用户要求判断文章、帖子、评论、图文、视频文案或公开链接是否侵害企业或企业家权益，或要求给出投诉建议、生成投诉通知时，使用本技能。

本技能直接完成研判与通知生成，不依赖旧的异步“内容违规检测”流程，也不要调用 `legal_check_create` 或 `legal_check_status` 代替本技能的逐句分析。

## 输入处理

1. 读取用户提供的正文、附件内容或公开链接。
2. 如果只有链接且无法取得正文，说明缺少可研判内容，请用户补充正文或有效截图；不要凭标题或链接地址猜测。
3. 区分原文事实、用户补充事实与尚未证实的主张，不得自行补造证据、传播量、主体身份或平台信息。

## 核心判定逻辑（S-01 分流标准）

在判定内容属于《涉企网络侵权信息举报工作规范》第十二条“侮辱性信息”还是第八条“误导性信息”时，必须遵循以下规则。

### 规则一：逐句判定，禁止整篇定性

1. **拆解**：将内容切分为独立表述单元。
2. **分类**：逐句标注为“事实主张 / 意见评价 / 情绪宣泄”。
3. **归轨**：
   - 含事实主张：归入误导或谣言的重举证轨道。
   - 纯人格贬损：归入侮辱的轻举证轨道。
   - 意见评价：原则上属于受保护的批评，除非同时包含可验证的事实指控或明显人格侮辱。

### 规则二：转化规则

凡贬损性称谓可以还原为具体违法或失德事实指控的，例如“骗子”可以还原为“实施欺诈”，一律按事实主张处理并转入重举证轨道。

### 规则三：反面清单

以下情形不当然构成侮辱：

- 尖锐的负面评价。
- 基于事实的讽刺。
- 对公开言行或经营行为的问责。

判断锚点是表述指向具体“行为”，还是无事实基础地攻击“人格”。

### 规则四：“煽动”要件

认定煽动时必须指出具体的动员性表述。不得仅以“用词负面”“评论区可能出事”或类似推测认定煽动。

### 规则五：存疑处理

分类存疑时一律归入重举证轨道，并明确列出需要补充的证据；不得为了得出侵权结论而降低举证要求。

## 工作流

1. 先给出一段不超过 100 字的决策摘要，结论只能是以下三类之一：
   - 可以投诉举报。
   - 不建议投诉举报。
   - 建议先补充证据后投诉举报。
2. 按 S-01 标准逐句输出判定清单，至少包含：原句或准确摘录、表述类型、法律定性、适用规则、证据要求。
3. 说明哪些内容不构成侵权以及原因，避免只列不利判断。
4. 只有在结论为“可以投诉举报”时，才根据已确认的事实生成《投诉通知》。
5. 缺少平台名称、文章标题、账号名称、投诉人名称或日期时，保留清晰占位符，不得编造。

## 投诉通知模板

**投 诉 通 知**

**{平台名称}平台：**

近日我司发现贵平台出现了标题为《{文章标题}》的内容（发布账号：“{账号名称}”）。经核查，该内容中的部分表述涉嫌违反《中华人民共和国民法典》《网络信息内容生态治理规定》以及中央网信办《网站平台受理处置涉企网络侵权信息举报工作规范》等规定，可能侵害我司及相关人员的名誉权益。

**一、侵权事实和投诉理由**

1. **{定性一}**：{逐句研判确认的具体表述、上下文及理由}。{对应的规则或法律依据}。
2. **{定性二}**：{逐句研判确认的具体表述、上下文及理由}。{对应的规则或法律依据}。
3. **{定性三，可选}**：{逐句研判确认的具体表述、上下文及理由}。{对应的规则或法律依据}。

上述事实以用户提供并能够证明的材料为限。删除不适用的条目，不得为了凑足数量而编造侵权事实。

**二、处置诉求**

请贵平台对上述内容依法依规进行审核，并根据核查结果采取删除侵权内容、断开相关链接或其他必要处置措施。

**三、真实性承诺**

我司承诺所提交信息和材料真实、准确、有效，并自愿承担因材料失实产生的相应责任。

此致！

投诉人：{投诉人名称}（盖章）

{日期}

## 输出要求

- 先给决策摘要，再给逐句判定清单，最后按条件给出投诉通知。
- 明确区分确定结论、合理推断和待补证事项。
- 不得把尖锐批评自动等同于侵权，不得虚构法律条款、证据或原文表述。
- 研判与文书仅供决策参考；涉及正式法律行动时，提示用户结合完整证据并咨询专业法律人士。
